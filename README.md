# claude-skills

Персональные скиллы для [Claude Code](https://claude.com/claude-code). Репозиторий
клонируется в `~/.claude/skills/`, откуда Claude Code подхватывает их автоматически.

## Скиллы

### `learn-topic`

Разбор технической темы до глубокого понимания — не «объясни, что такое X», а
полноценное прохождение темы с проверкой знаний и практикой.

**Проблема, которую решает.** Код пишется по референсу и работает, но воспроизвести
по памяти не получается, а под капотом остаётся туман. Обычный диалог с ассистентом
это не лечит: объяснение прочитано, кивнул, через неделю ничего не осталось, а
проверить себя нечем.

**Как работает.** Цикл из шести фаз, состояние хранится в файлах, а не в контексте чата:

```
theory.md  →  quiz.md  →  проверка  →  закрытие пробелов  →  практика  →  закрытие темы
```

- **Теория** пишется в `theory.md` темы. Большие темы идут блоками: блок теории →
  вопросы по нему → разбор → следующий блок. Монолит на объёмной теме не работает.
- **Квиз** — `quiz.md` с пустыми полями `**Твой ответ:**`, заполняется прямо в файле.
  Покрыт каждый смысловой раздел теории, перекос веса — на ловушки. Есть вопросы
  «напиши код», а не только на понимание.
- **Проверка** — код из ответов **реально компилируется и запускается**, а не читается
  глазами. Самые опасные ошибки компилируются чисто и ломаются только в рантайме.
- **Пробелы** закрываются прямым объяснением, без сократовских наводящих вопросов.
  Решение за ученика не пишется — показывается дефект и механизм, правку вносит он сам.
- **Практика** обязательна даже для маленьких тем. Интеграционная оформляется как
  `TASK.md` — ТЗ словами, без готового кода.
- **Повторение** — в конце темы секция с вопросами по уже закрытым темам. Ловит регрессы.

**Ключевые правила.** Код никогда не проверяется чтением. Вопрос проверяет только то,
что было в теории, — если ученик говорит «этого не было», это недоработка теории, а не
его пробел. Ошибка в секции повторения означает, что тема закрыта не была, и
переоткрывает её статус. Содержимое файлов не дублируется в чат.

Метод не привязан к языку программирования — подойдёт для любой технической темы,
которую нужно разобрать до дна.

## Установка на новой машине

```bash
git clone git@github.com:ReGo2552/claude-skills.git ~/.claude/skills
```

Если `~/.claude/skills/` уже существует и не пуст — клонировать рядом и слинковать:

```bash
git clone git@github.com:ReGo2552/claude-skills.git ~/claude-skills
ln -s ~/claude-skills/learn-topic ~/.claude/skills/learn-topic
```

После создания папки `~/.claude/skills/`, которой не было при старте сессии, Claude Code
нужно перезапустить — иначе он не начнёт за ней следить. Дальнейшие правки файлов
подхватываются на лету, без рестарта.

## Использование

Скилл вызывается явно — `/learn-topic` — либо подключается сам, когда по запросу видно,
что речь о полноценном прохождении темы («давай пройдём X», «проверь мои ответы»,
«напиши теорию по X»). На одиночных вопросах вроде «что делает defer» не срабатывает.
